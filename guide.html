StayBUT 사용 안내

객실 QR로 외국인 손님과 자동 번역 대화 · 청소 자동 생성 · 여러 채널 예약 한 화면에

손님이 객실 QR을 찍으면 바로 문의할 수 있고, 어떤 언어로 써도 한국어로 번역되어 보입니다. 사장님은 한국어로 답하면 손님 언어로 번역돼요.
전체 플랜을 쓰시면 여러 채널 예약이 한 화면에 모이고, 퇴실마다 청소가 자동으로 생성됩니다.

두 가지 플랜

문의만
세팅 5분 · 예약 연동 불필요
  • 객실 QR + 7개 언어 자동 번역
  • 자주 쓰는 답변 버튼
  • 새 문의 알림
전체
문의 + 예약·청소
  • 문의 기능 전부 포함
  • 여러 채널 예약을 한 화면에
  • 퇴실마다 청소 자동 생성 · 카톡 브리핑
문의만으로 시작해서 나중에 전체로 올리셔도 됩니다. 데이터는 그대로 유지돼요.

처음 세팅

1

로그인

전달받은 링크에서 비밀번호를 설정한 뒤 admin.staybut.kr/host.html 로 로그인하세요.

휴대폰에서도 됩니다. 자주 쓰신다면 홈 화면에 추가해 두세요.
2

숙소 등록

숙소 관리(또는 채널 연결) 화면에서 + 숙소 추가로 운영하는 숙소를 등록하세요. 이름은 자유롭게 적으면 됩니다 (예: 강남점, 101호).

여기 등록한 숙소마다 QR이 하나씩 만들어져요.
3

QR 붙이기

QR 코드 화면에서 숙소별 QR을 저장하거나 인쇄해, 객실 안(안내판·냉장고·현관)에 붙여주세요.

객실 안에 붙이는 게 중요해요. 방에 들어온 손님만 문의할 수 있어 대화가 섞이지 않습니다.
4

예약 달력 연결 전체 플랜

숙소마다 실제로 판매하는 채널 칸에만 달력 주소(iCal)를 붙여넣고 저장하세요. 붙여넣으면 "예약 N건 감지"로 맞는 주소인지 바로 확인됩니다.

이후 15분마다 자동으로 예약이 채워지고, 퇴실일마다 청소가 생성돼요.

달력 주소(iCal) 받는 곳 전체 플랜

채널경로
부킹닷컴익스트라넷 → 요금 및 예약 가능 여부 → 캘린더 → "캘린더 동기화 / iCal 내보내기"
에어비앤비리스팅 → 예약 가능 여부 → 캘린더 연결 → "캘린더 내보내기(.ics)"
아고다YCS(익스트라넷) → 캘린더/동기화 → 내보내기 링크
주의 — 달력 주소는 숙소마다 다릅니다. 해당 숙소 칸에 정확히 넣어주세요.
부킹닷컴은 숙소 유형에 따라 iCal 내보내기가 없을 수 있어요. 없으면 예약을 직접 입력하거나 파일로 올릴 수 있으니 문의해 주세요.
참고 — StayBUT는 예약을 읽어서 보여주는 도구예요. 한 채널이 팔리면 다른 채널을 자동으로 막아주는 기능(재고 동기화)은 없습니다. 그건 채널끼리 달력을 서로 연결해 두시면 됩니다.

매일 어떻게 쓰나요

화면여기서 하는 일
상담손님 문의 응대 · 자동 번역 · 자주 쓰는 답변
QR 코드숙소별 QR 저장·인쇄

예약 관리 전체모든 채널 예약을 한 표에서 · 이전·다음 달 이동

청소는 자동입니다. 예약이 들어오면 퇴실일에 청소 일정이 저절로 생겨요. 담당자만 정해 주시고, "청소 브리핑 공유"를 누르면 수량까지 정리된 문구가 나와 카톡에 그대로 붙여넣을 수 있어요.

자주 묻는 질문

손님이 어떤 언어로 써도 되나요?

네. 영어·중국어·일본어·독일어·프랑스어·스페인어 등 대부분 언어가 한국어로 자동 번역돼요. 사장님은 한국어로만 답하시면 됩니다.

손님 이름·연락처는 보이나요?

보이지 않습니다. StayBUT는 날짜와 숙소 정보만 다루고 손님 개인정보는 저장하지 않아요. 문의 내용은 90일 후 자동 삭제됩니다.

QR을 객실 밖에 붙여도 되나요?

객실 안을 권해요. 방에 들어온 손님만 문의하게 되어 이전·다음 손님과 대화가 섞이지 않아요. 도착 전 문의는 부킹닷컴·에어비앤비 메시지로 받으시면 됩니다.

예약이 바로 안 보여요 전체

달력은 15분마다 확인합니다. 방금 들어온 예약은 잠시 후 표시돼요.

문의만 쓰다가 전체로 바꿀 수 있나요?

네. 말씀해 주시면 바로 전환해 드려요. 그동안의 문의 내용은 그대로 유지됩니다.

요금은 얼마인가요?

현재 무료 시범 운영 중입니다. 유료로 전환할 경우 미리 안내드리며, 동의 없이 과금되지 않습니다.
